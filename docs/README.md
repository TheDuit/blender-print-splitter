# Project documentation

Blender Print Splitter is a Sculpt Mode add-on for preparing a mesh as separate printable parts.

- Start with the [user guide](USER_GUIDE.md).
- Read the [architecture overview](ARCHITECTURE.md) before changing mesh or connector behavior.
- Use the [development guide](DEVELOPMENT.md) to build the extension and run manual checks.
- Look up common failures in [troubleshooting](TROUBLESHOOTING.md).
- The [action plan](../PLAN.md) tracks implementation status and planned work.

The add-on UI and project documentation use English by default. The declared minimum is Blender 5.3.0.
